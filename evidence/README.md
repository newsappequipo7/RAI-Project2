# Evidencia

- `loops/` — engineering loops (`LOOP-XXX.md`), creados con `/registrar-loop`.
- `evals/` — salidas JSON de `pnpm evals:chat` (una por corrida, con fecha).
- `demo-videos/` — videos de respaldo por sección de la presentación.
- `captures/` — capturas nombradas con el ID de tarea: `F3-07-disputada-iphone.png`.

Regla: todo criterio de aceptación marcado como cumplido en `docs/PLAN.md` §6 enlaza a algo de esta carpeta o a un PR.
